## 브라우저 수동 검증

- 가을호 표지 및 두 쪽 렌더링
- 다음 연속 3회: 7–8쪽 그림, 표시, 주소 일치
- 서재 복귀 뒤 방향키: 뷰어 접근 오류 없음
- 뷰어 재진입: 7쪽 이어 읽기
- 390×844 모바일 화면: 한 쪽 보기, 도구 표시
- 60쪽 직접 이동: 마지막 쪽 렌더링, 다음 비활성
- 확대: 스크롤로 큰 페이지 열람 가능
- 별도 로컬 테스트 폴더에서 PDF 404: 실패 안내, 저장 비활성, 재시도 제공
- 파일 복구 후 재시도: 봄호 1–2쪽 정상 렌더링
- 정상 시나리오 브라우저 오류 로그 없음

## 범위

GitHub Pages의 정적 뷰어를 개선했다. Sites/React 경로는 기존 배포 연결 보존과 빌드 회귀 확인 대상으로 유지한다. 실제 휴대전화 기기나 모든 브라우저 조합은 검사하지 않았다. PDF 자체는 압축하지 않았으므로 최초 다운로드 크기는 기존과 같다.
